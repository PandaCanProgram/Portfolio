# Portfolio

John Anthony Lontoc's personal portfolio — React + Vite, content driven by JSON files in `src/data/`.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Deploy

Deployed on Vercel — connect this repo and Vercel will detect the Vite preset automatically (build command `npm run build`, output directory `dist`).

## Content

Edit the JSON files in `src/data/` to update site content without touching component code:

- `hero.json` — name, role, tagline, hero buttons
- `about.json` — bio copy and quick facts
- `projects.json` — work/project entries
- `skills.json` — skills grouped by category
- `contact.json` — email, GitHub, contact blurb
